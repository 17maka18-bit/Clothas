✨ Clothas — Spirit of Fashion

A modern and stylish fashion website built with HTML and CSS.

👗 About the Project

Clothas is a fashion website concept designed to showcase modern clothing, sneakers, accessories, and popular fashion brands.

The website features a dark background, purple gradients, stylish product cards, and a responsive layout.

✨ Features

- Modern fashion-inspired design
- Responsive layout for mobile and desktop
- Hero section with a fashion introduction
- Clothing, shoes, and accessories collections
- Trending fashion section
- Popular brands section
- Frequently Asked Questions (FAQ)
- Built using HTML and CSS only

🛠️ Technologies Used

- HTML5
- CSS3

🚀 How to Run

1. Clone or download this repository.
2. Open "index.html" in your browser.
3. Enjoy the Clothas fashion website!
